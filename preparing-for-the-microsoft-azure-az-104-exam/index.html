Preparing for the Microsoft Azure AZ-104 Exam

Cloud Sun 13 September 2026 · 4 min read · Ashley Kleynhans

I recently prepared for the Microsoft Azure Administrator Associate AZ-104 exam. In this post I want to share what worked, what did not, and what I wish I had known before I started.

Starting with Udemy

I started with this Udemy course:

  • AZ-104 Microsoft Azure Administrator - Complete Exam Prep

It did not cover sufficient detail for AZ-104. The breadth is there at a high level, but the depth on key exam domains like identity, governance, storage, compute, virtual networking and monitoring was not enough to feel confident for the exam.

Next I tried:

  • AZ-104 Microsoft Azure Administrator Course with Simulations

The content coverage is better, but the simulations are basically clicking on screenshots. You are not navigating the real Azure portal or creating real resources, so you do not build the muscle memory you need for the portal-based tasks and case study style questions.

Why Whizlabs Was Significantly Better

I then moved to the Whizlabs Microsoft Azure Certification AZ-104 Training Course and it was a clear step up for two reasons: hands-on labs and better assessment.

Hands-on Labs in the Real Portal

The Whizlabs labs let you navigate the actual Azure portal and create actual resources, rather than clicking through static images. For AZ-104 that matters. A lot of the exam tests whether you know where settings live in the portal and in what order to configure them. Building that familiarity in a live environment made a real difference.

Whizlabs also offer a standalone sandbox for around $20, but I did not find it necessary. Each lab in the training course grants sandbox access to complete the lab, which was sufficient for my preparation.

Quizzes and Practice Tests

Each section in the Whizlabs course has a quiz to test your knowledge, which is useful for reinforcing what you just covered and identifying gaps early.

For exam preparation, Whizlabs includes a free practice test, 5 additional practice tests, and a final test. In my experience these tests are far more representative of the real exam than:

  • the set of 4 practice tests on Udemy at AZ-104 Azure Practice Tests, or
  • the official practice tests on Microsoft Learn at Practice Assessment for AZ-104

Microsoft Learn says "To be better prepared for the exam, aim to achieve a score of 80% or higher in multiple attempts." That is reasonable advice, but the Microsoft Learn practice test itself is significantly easier than the real exam in my experience. If you only use that as your benchmark you may walk in underprepared.

I found the Whizlabs tests and the Pearson Practice Tests via O'Reilly to be much closer to the difficulty and style of the real thing.

Pearson Practice Tests Tip

One important thing to be aware of for the Pearson tests: you need to configure each test by unchecking all of the others, otherwise you will keep getting the same test. The combined test seems to pull questions from each of the 5 practice tests and does not seem to randomise questions even with the randomise questions configuration set to "On". Select a single test at a time if you want focused, repeatable practice on each set.

The Cheat Sheet

Whizlabs also provide a 166 page cheat sheet. It is dense, but it is worth going over before you sit the exam as a final review. I used it as a last pass to catch topics I had not revised recently.

What I Would Skip

I do not recommend using the practice exams on Tutorials Dojo for AZ-104. I found some of the material to be incorrect, which is the opposite of what you want when you are trying to calibrate your readiness.

An Extremely Valuable Microsoft Resource

One resource I highly recommend before you book your exam date:

  • Exam duration and exam experience

It explains the exam format, timing, question types, case studies, and what the lab-like tasks look like. Knowing what to expect removes a lot of uncertainty on exam day.

Exam Day Tips

Use an External Mouse

The exam includes a whiteboard. If you are taking the exam remotely on a laptop, the whiteboard is not very easy to control using a trackpad. I recommend using an external mouse if you are sitting the exam remotely.

Walk-in Test Centre vs Online Proctoring

If you live close to a walk-in test centre, I recommend taking the exam from the walk-in centre where possible rather than taking it online. For online proctored exams you need to make sure your exam environment meets the requirements by taking pictures and showing the proctor your room on your webcam. That process can lead to unnecessary stress and anxiety before the exam even begins. At a test centre you can just arrive, check in, and focus on the exam.

Summary

If I were starting again, I would:

  1. Skip the screenshot-based simulations and spend that time in real portal labs. The Whizlabs hands-on labs were the most effective part of my preparation.
  2. Use the section quizzes and the full practice tests from Whizlabs as my primary readiness gauge, supplemented by the Pearson practice tests.
  3. Treat the Microsoft Learn practice assessment as a useful knowledge check, but not as a difficulty benchmark. Aim for well above 80% there and still expect the real exam to be harder.
  4. Review the Whizlabs cheat sheet in the final days before the exam.
  5. Read the official exam experience page so the format is not a surprise.
  6. Use an external mouse for the whiteboard and, if convenient, choose a walk-in test centre over online proctoring.

Good luck if you are preparing for AZ-104. The exam is broad and practical, but with the right hands-on practice and realistic practice tests it is very manageable.
